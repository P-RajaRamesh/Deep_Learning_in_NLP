# Simple RNN #
IMDB Movie Review Sentiment Analysis
IMDB Movie Review Sentiment Analysis
🚀 Built an interactive IMDB Movie Review Sentiment Analysis web app using TensorFlow and Streamlit! The application leverages a pre-trained Simple RNN model with ReLU activation to classify user-submitted movie reviews as positive or negative. It preprocesses text input by tokenizing and padding sequences, then feeds it into the model for real-time prediction. The clean, user-friendly interface allows anyone to quickly gauge the sentiment of their movie reviews.
