## Word Prediction ##

🚀 Developed a Streamlit web application for Next Word Prediction using NLTK techniques and LSTM model trained on sequential text data. The app takes a sequence of words as input and predicts the most likely next word based on learned language patterns. It integrates a trained LSTM model and a tokenizer for preprocessing. Key features include dynamic sequence padding, early stopping during training, and a clean interactive interface for real-time predictions.
